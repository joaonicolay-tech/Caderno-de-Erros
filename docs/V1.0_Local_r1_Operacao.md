# V1.0 Local r1 — operação e limites

O [pacote público de fonte](V1.0_Local_r1_Fonte.md) permite verificação sintética.
Não provisiona uma instalação para dados pessoais. A instalação privada aceita
mantém sua identidade e seus procedimentos próprios; os limites abaixo não
autorizam trocar banco, segredo ou caminho de uma instalação já existente.

## Demonstração sintética

Depois do preparo e gate documentados, use production_local/DEBUG=False,
127.0.0.1 e Chrome. Conteúdo inventado somente. O launcher permanece uma janela
PowerShell encerrada com Ctrl+C. Sem exposição em 0.0.0.0, serviço ou atualização
automática. O build usa estáticos locais, incluindo o aviso de licença do htmx.

## Backup e retorno

Backup físico SQLite + manifesto é diferente do ZIP de exportação CEI. Não há
merge/importação histórica na rota Local r1. A validação de backup não autentica
o autor; mantenha origem e arquivo/manifesto juntos.

A UI oferece preview/cancelamento e preparação de restore. A aplicação do ticket
é offline, com o próprio servidor parado, pré-backup válido e destino admitido:

```powershell
.\.venv\Scripts\python.exe manage.py apply_prepared_restore --ticket ID_DO_TICKET
```

Esse comando não instala nem ativa a aplicação. No pacote de fonte, use-o apenas
em cenários sintéticos próprios. Não substitua arquivos do banco manualmente.
Reabra e reconcilie histórico, pendências, métricas e checker após retorno.

Na instalação privada previamente qualificada, com mudanças em uso, a cadência
aprovada é manual, no máximo a cada 24 h; manter sete versões diárias e quatro
semanais à medida que forem produzidas. Não há rotação destrutiva automática.
Uma segunda mídia própria verificada é necessária para sustentar proteção contra
perda física; o exercício de processo não demonstrou falha de disco/host/energia.

## Limites preservados

Chrome somente; Edge não qualificado. CT-126 adiada, quatro LIMITED temporais,
perfil BCR sintético, dispositivo único e histórico preservado conforme as
[notas](RELEASE_NOTES_V1.0_LOCAL_R1.md). A próxima versão tratará interface visual
e inicialização; este pacote não introduz launcher avançado ou novo fluxo de estudo.
