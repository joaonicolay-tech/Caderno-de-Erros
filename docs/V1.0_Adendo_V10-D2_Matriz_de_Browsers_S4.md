# Adendo V1.0-S4 — Matriz de browsers de V10-D2

## Proveniência e alcance

Este adendo registra a decisão humana persistida na seção
`Human Decision Addendum — Browser Support V1` de `tasks/current.md`.
A decisão altera somente o conjunto de browsers obrigatórios para validação de
release V1. Não reescreve V10-D2 no plano aprovado, a matriz congelada de S1,
nem evidências históricas P0/S1.

## Política de browser V1 em vigor

- É necessário um PASS completo em Windows 11 x64 em Brave estável atual OU
  Google Chrome estável atual. O browser que passar será declarado validado
  para V1.
- Permanecem os critérios de fluxos centrais, acessibilidade, teclado, foco,
  labels/semântica, erros/recuperação, zoom 200%, usabilidade e responsividade
  de 360–1920 px.
- A condição específica do Brave em V10-D2 — configuração padrão e sem
  extensões — permanece quando Brave é o browser escolhido.
- Edge e Firefox atual/anterior são opcionais
  (`NOT_EXECUTED / OPTIONAL`); não declarar validação/suporte oficial sem
  execução e PASS.
- Safari permanece `N/A / NOT TECHNICALLY APPLICABLE TO THE SUPPORTED V1
  PLATFORM`, pois a plataforma oficial é Windows 11 x64.
- Não há suporte mobile novo.

Todos os demais limites de plataforma, distribuição e produto em V10-D2
permanecem inalterados.

## Incidentes e fronteiras

- O controle visual do Codex falhou anteriormente com
  `helper_unknown_error: apply deny-read ACLs`. O Codex não repetiu a
  automação; a validação final descrita aqui é manual e fornecida pelo
  responsável.
- O responsável relata crash do processo Chrome durante tentativa de
  automação. Chrome não foi aprovado nem declarado testado com sucesso.
- Na preparação, o responsável relata
  `OperationalError: no such column: errors_error_category.category_kind`.
  O banco local ainda não tinha aplicado
  `errors.0003_errorcategory_category_kind_and_more`; foi feito backup local
  e aplicada a migration já existente. Isso foi preparação ambiental, não
  migration criada por S4. Banco e backup não foram versionados nesta tarefa.
- Não foi reportado finding reproduzível de produto. Nenhuma migration,
  alteração funcional, feature ou redesign foi criada nesta S4.
