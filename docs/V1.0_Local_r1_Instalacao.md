# V1.0 Local r1 — alcance da instalação

Esta é uma distribuição de **código-fonte reproduzível**, não um instalador
universal. O [guia de fonte](V1.0_Local_r1_Fonte.md) contém os pré-requisitos,
preparação em diretório novo, gate e build com hashes. A execução pública
preparada por esse procedimento é somente sintética.

A entrega privada v014 foi aceita para uma instalação específica. Sua proteção
de armazenamento, segredo e autorização de uso real não acompanham um download.
Não copie banco, .local-r1.json, secret.txt, autorizações REAL_USE ou evidence
da instalação privada para um clone ou outro computador. Não altere os flags
para habilitar dados pessoais. Este pacote não fornece essa ativação.

O build não exige recibos privados. Runtime e dependências são fixados e podem
precisar de internet. O preparo cria uma cópia em candidate e slots sintéticos
somente num destino novo, sem tocar ou adotar uma base existente. Chrome desktop
é o navegador contemplado; Edge não qualificado.

Para a instalação privada já liberada, mantenha seus guias e launcher aprovados.
Não execute migrations, importação ou atualização sobre seu banco por este guia.
Consulte também [operação e limites](V1.0_Local_r1_Operacao.md).
