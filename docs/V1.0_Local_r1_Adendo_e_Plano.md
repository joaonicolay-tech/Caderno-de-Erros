# Local r1 — reconciliação da distribuição pública de fonte

Este adendo aplica-se à preparação pública de código-fonte 1.0.0 Local r1.
A autorização atual do responsável abrange integração, correções de distribuição,
testes proporcionais e commits locais. Push, tag e GitHub Release continuam
dependentes de autorização posterior. O contrato da tarefa é arquivado ao fim.

A instalação privada v014 foi aceita para novos dados individuais em seu
perímetro qualificado. Esse aceite não é transferido para a fonte derivada,
um novo host ou um novo diretório. A distribuição pública fornece build
determinístico e preparação/verificação sintética, sem provisionamento REAL_USE.
Isso não é uma liberação estável da rota histórica de migração de acervo.

Para esta distribuição, os documentos de entrada são README,
[fonte](V1.0_Local_r1_Fonte.md), [instalação](V1.0_Local_r1_Instalacao.md),
[operação](V1.0_Local_r1_Operacao.md) e
[notas](RELEASE_NOTES_V1.0_LOCAL_R1.md). Eles prevalecem sobre orientações
incompatíveis de checkout genérico, desenvolvimento, override de banco,
importação/upgrade histórico e suporte Brave/Edge nas fontes anteriores.

Chrome desktop é o escopo atual, com observação humana anterior em
157.0.8103.39; Edge não qualificado. CT-126 permanece adiada/não qualificada,
sem novo teste humano, PASS ou defeito inferido. Quatro LIMITED temporais,
resultados BCR brutos, limites de recuperação e backup manual são preservados.

ADRs de perfis e qualidade continuam com seus controles materiais. A raiz é
derivada do layout fixo da instância, sem variável de ambiente para trocar o
banco ou contornar contenção. O gate de fonte scripts/quality-source.ps1
opera somente sobre uma cópia nova sintética e lista positiva, sem depender
dos gates privados de aceite ou enumerar armazenamento histórico.

Não há migration nova, mudança de regra de estudo, redesign ou launcher
avançado. Os originais privados, STOPs, retenção, seis commits locais anteriores
e estados históricos A8/F01–F03/HD-01/02/CP7/S8 não são reescritos ou encerrados.
Os estados aceitos S8/S9/S10 Local r1 pertencem à entrega privada v014.

Após a V1.0: melhorar a interface visual e simplificar a inicialização, em
escopos próprios; depois dessas melhorias, realizar a auditoria completa do
GitHub solicitada pelo responsável. Este trabalho não antecipa essas etapas.
