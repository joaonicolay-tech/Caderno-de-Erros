# V1.0 Local r1 — reproduzir o código-fonte

O pacote permite reproduzir o código, o lock, o build e a regressão sintética.
Não provisiona dados pessoais nem qualifica uma instalação real em outro host.
Uma instalação privada já aprovada deve continuar usando seus próprios arquivos
e procedimentos; não a sobrescreva com este checkout.

## Ambiente

Windows 11 x64, volume local C:, PowerShell 5.1+, uv 0.12.7 e internet para obter
CPython 3.13.15 e as dependências de uv.lock. O runtime esperado inclui Django
5.2.17 e SQLite 3.53.1. Não há promessa de instalação offline ou de plataforma
móvel. Um ambiente virtual novo é criado; não copie .venv de outra instalação.

Confira `uv --version`. Se necessário, instale a versão fixada pelo distribuidor:

```powershell
powershell -ExecutionPolicy Bypass -c "irm https://astral.sh/uv/0.12.7/install.ps1 | iex"
```

Use uma pasta nova para o checkout ou para extrair o ZIP de fonte publicado.
Se estiver usando Git, confira o SHA informado na release. Enquanto não houver
tag publicada, use a branch/SHA de preparação fornecida pelo responsável; não
trate v0.5.0 como V1.0. Confira o SHA-256 e execute `verify` se houver o ZIP curado.

## Preparação sintética

Na raiz do código, confirme que existem pyproject.toml, uv.lock e manage.py:

```powershell
uv sync --locked
uv run --locked python scripts/source_release.py prepare --destination C:\CEI-source-check
Set-Location C:\CEI-source-check\candidate
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\quality-source.ps1
```

`C:\CEI-source-check` é um exemplo de **destino novo e vazio**: substitua por uma
pasta nova em C: sob seu controle, cujo diretório pai já exista. Não use pastas
de dados existentes, rede, sincronização compartilhada ou links/junctions. O
preparo recusa colisão; não apaga nem adota conteúdo. Ele copia somente a lista
pública e cria candidate, validation, backups, marcador e segredo sintéticos.
Não cria user/installed, autorização REAL_USE ou recibos de aceite privado.

O gate confere lock/runtime, lint/formatação, tipagem, checks, migrations, banco
vazio, regressão com cobertura, links, baseline, segredos e dependências. Logs e
resultados ficam exclusivamente em validation/gate-ID; falhas não são apagadas.
Auditoria de dependências exige rede e não vira PASS se estiver indisponível.
O gate histórico scripts/quality.ps1 e os contratos S8 antigos não são o roteiro
desta distribuição. O gate público não refaz a aceitação histórica S8/S9/S10.

Para uma demonstração vazia e somente sintética, após o gate:

```powershell
.\.venv\Scripts\python.exe manage.py bootstrap_local --timezone America/Sao_Paulo
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-local.ps1
```

Abra http://127.0.0.1:8000/ no Chrome. Use apenas conteúdo inventado. A preparação
fica `user_enabled=false`; isso identifica verificação sintética e não libera
uso pessoal. Pare a própria janela com Ctrl+C. Não mude o flag para contornar
qualificação: a ativação real exige os controles privados completos e não é
fornecida por este pacote. Porta ocupada exige escolher outra porta ou encerrar
conscientemente o próprio processo, nunca matar outro aplicativo automaticamente.

## Build determinístico

Na raiz de um checkout ou pacote de fonte, com o ambiente fixado disponível:

```powershell
uv run --locked python scripts/source_release.py build --output ..\cei-1.0.0-local-r1-source.zip
uv run --locked python scripts/source_release.py verify ..\cei-1.0.0-local-r1-source.zip
Get-FileHash ..\cei-1.0.0-local-r1-source.zip -Algorithm SHA256
```

O destino do ZIP deve ser novo. Nomes, ordem, permissões, timestamps e finais de
linha são canônicos; a mesma fonte gera os mesmos bytes. O build confere duas
gerações e todos os hashes. quality/source-files.json é a lista positiva;
SOURCE-MANIFEST.json identifica cada membro. Esse manifesto prova integridade,
não autentica o autor: confira também o SHA Git e o checksum obtido do canal
do responsável. Não copie marcadores/segredos para reproduzir a identidade v014.

O aceite privado v014 permanece uma referência de proveniência. A derivação
pública altera a resolução da raiz, ferramentas e documentação e tem uma nova
identidade de artefato. Não reivindica teste de outro computador, usabilidade
CT-126, suporte Edge ou nova aprovação S10 para dados reais.
